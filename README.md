# homebrew-splat

[Homebrew](https://brew.sh) tap for [`splat`](https://github.com/daanrongen/splat). Apple Silicon macOS only.

```sh
brew tap daanrongen/splat
brew install splat
```

`Formula/splat.rb` is generated and pushed here automatically by [splat's publish workflow](https://github.com/daanrongen/splat/blob/main/.github/workflows/publish.yml) on every tagged release. Don't edit it by hand.
